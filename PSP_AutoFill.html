One-time setup needed — add your Google OAuth Client ID:

1. Open this HTML file in a text editor (Notepad, TextEdit, VS Code)
2. Find the line near the top of the <script> that says:
const CLIENT_ID = '';
3. Paste your Client ID between the quotes
4. Save and refresh this page

To get a Client ID:
1. Go to Google Cloud Console → Credentials
2. Create an OAuth 2.0 Client ID → Web application
3. Add null as an authorised origin (for local file use, see note below)
4. Enable Google Sheets API and Google Drive API in your project
